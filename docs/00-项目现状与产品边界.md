# 项目现状与产品边界

> 状态日期：2026-08-31。本文描述活动代码，不用历史计划推断能力。

## 产品定位

ResearchPath（研径）是 Windows 本地优先、从研究规划或已有数据出发的实证研究与可视化建模工具。React 提供交互，FastAPI 管理数据、契约、任务与持久化，R 执行统计估计。目标用户是需要可复现分析与结构化导出的个人研究者，不是云端协作平台或自动“找显著”系统。

首屏先区分规划新研究与分析已有数据。已有数据分析再分别声明：

1. 时间结构：单次/横截面、追踪面板、密集追踪；
2. 依赖结构：独立或聚类/嵌套；
3. 研究设计：观察性、随机实验或非随机比较。非随机比较保留内部 `quasi_experimental` 值以兼容既有项目，但当前不对外声明准实验因果识别能力。

数据字典确认和适用的研究结构是分析入口的前置条件。测量版本按方法需要创建，不再是所有统计分析的全局门槛：原始变量的描述、频数、缺失、相关、组间比较、回归、相对重要性与响应面可以没有测量版本；构念计分、量表方法及当前 PROCESS/SEM、面板和日记专用流程仍绑定测量版本。功效规划不要求真实数据；其他方法以当前能力注册表的上下文和前置条件为准。

## 当前正式接线

| 领域 | 活动入口 | 当前边界 |

| 数据与测量 | `apps/web/src/App.tsx`、`apps/api/app/api/routes/datasets.py` | CSV/XLSX/SAV/DTA/POR、变量识别、数据版本、量表计分、信度与项目分析 |

| PROCESS 5.0 识别 | `process_catalog.py`、`ModelBuilder` | 反向识别 55 个当前预编程编号；合法自定义拓扑单独分类 |
| PROCESS/SEM 估计 | `analysis_jobs.py`、`run_analysis.R` | 55 个 PROCESS 5.0 编号结构可执行；OLS、logistic 和 SEM |
| 上下文专属方法 | `AdvancedAnalysisManager`、`routes/advanced.py`、`run_advanced_analysis.R` | 两层 Gaussian LMM/ICC/rwg、实验设计、通用功效与精度、分析绑定 MI、带声明 Target 的连续 ESEM、连续/有序 Bifactor、二元 2PL 与多分类 GRM IRT/DIF |

方法注册表的 `executionAvailable=true` 只表示当前 runner 可以执行；它不表示已完成独立数值验证，更不表示可直接作为论文主分析。每个活动切片同时返回由 `validationEvidence` 派生的 `validationLevel`（`unvalidated`、`internally_validated`、`externally_validated`）、`maturityLevel`（`experimental`、`validated`、`reviewer_ready` 或 `publication_ready`）和 `publicationEligibility`（`ineligible`、`conditional` 或 `eligible`）。当前没有活动切片标记为 `publication_ready/eligible`：论文主分析仍需冻结研究计划、估计对象、样本流、结果身份与导出证据图。当前五个上下文方法 family 已注册 runner，但内部仍按切片声明边界，不能扩写为任意多层模型、实验、功效、插补或测量模型。

## 已确认的前端现状

- 实证配置按“选择方法 → 指定变量/构念 → 参数 → 显式运行 → 本次结果”组织；各方法独立配置，不强制依次跑基础、测量与回归。
- 顶层先选择规划或分析；已有数据路径由 `StudyContextSwitcher` 分别声明时间、依赖和设计属性。
- 嵌套横截面有专属结构与测量准备：cluster 角色、组规模、ICC/rwg、聚合证据和多层模型边界在进入分析前可见；系统不以固定阈值自动宣布“可聚合”。cluster 聚合变量与组间比较/等值性变量是两个独立契约字段。
- 本地处理架构是浏览器 → localhost HTTP API → 本机 FastAPI → 本机 R worker/子进程；研究数据不上传到远端云服务，但会经过本机网络栈，数据版本、任务和报告可在本机工作区持久化。产品不得宣称浏览器 WebAssembly 内计算或零网络传输。
- 变量列表支持搜索与点选；方法按适用性呈现，参数配置和运行前完整性检查服务当前选中的分析。
- 纵向与日记结果使用独立页签，只在报告含相应 segment 时显示可分析状态。
- 通用结果页不再混入固定样例的纵向泳道或 Mock ESM 轨迹。
- SEM 可切换测量图、结构图和完整模型；可展开/折叠指标，编辑构念题项和高阶构念。显示折叠不改变估计规格；载荷与路径统计来自本次真实结果。当前画布不是任意 SEM 语法编辑器，未登记的协方差或动态模型不能靠画线解锁。
- 方法目录传递具体 SEM、纵向或日记切片。变更已有草稿的模型类型或选项前说明影响并确认；同类 SEM 重新打开不会重置自定义测量。返回目录不自动估计。
- 单项实证草稿按数据内容、字典、测量和上下文身份分别保存在浏览器；切换方法、刷新与返回工作台可恢复。已提交任务由服务端持久化，恢复只重连、不自动重跑；上游版本变更会进入新草稿。模型草稿由服务端恢复，重新编辑须重新冻结。
- 高级方法专属图只消费实际返回字段；没有曲线、链或题目级结果时显示边界说明，不合成示例数据。
- 结果页签按真实报告 segment 判定状态，不用“组件文件存在”代替可达性。
- 模型画布只把区间是否跨 0 或 p 值描述为“推断信号/推断不确定”；不再用显著性星号、勾叉或颜色把单条路径包装为理论支持/不支持，且置信区间优先于 p 值。

## PROCESS 5.0 识别与执行边界

目录版本为 `5.0`，覆盖编号 1–22、28–29、58–73、75–76、80–92，共 55 个当前预编程模型；Model 74 不在当前目录。服务端返回结构有效性、匹配状态、编号、显示名、目录版本、可执行性与不支持原因。

55 个目录编号在满足各自中介数量约束时均返回 `executionAvailable=true`。55 个有效预设均可在前端搜索、预览、配置允许的中介数量并直接应用；保留 14 个常用快捷入口，自由画布也可反向识别。合法但没有编号的拓扑仍显示为自定义模型，可保存、冻结和导出设计，但任务服务拒绝运行。

PROCESS 编号执行仅接受连续或 0/1 二分类的 X（W/Z 与协变量同样要求连续或二分类）；M（中介变量）只接受连续变量，二分类中介在运行前守门拒绝并返回 `BINARY_MEDIATOR_NOT_SUPPORTED`——logit 方程的中介路径系数与 OLS 结果方程系数相乘不构成可解释的间接效应。多类别 X——即官方宏的 `mcx` 功能（Hayes 书内 protest 示例等）——当前不执行，运行前守门按设计拒绝并返回 `PROCESS variable x must be continuous or binary`，该行为有 `engine/R/tests/testthat/test-public-data-oracle.R` 的边界测试佐证。这些限制不是模型拓扑不匹配，而是变量编码层与估计尺度的显式产品边界。

编号估计器是基于公开模型拓扑的独立实现，不在仓库中复制或分发官方宏。它按每个内生变量编译回归方程，枚举特定与总间接路径，计算 W/Z 条件效应、多项式指数和 Bootstrap 区间。代表值使用 PROCESS 5.0 的第 16、50、84 百分位（type-6 分位数）；同一路径含 W、Z 或 W×Z 时使用完整协方差矩阵联合探查。当前数值门禁覆盖全部编号的方程级 NumPy 对照，并以官方 PROCESS 5.0 R 宏在确定性合成数据上生成的五模型金标准（Model 1/4/6/7/14，含 percentile/BCa Bootstrap 区间与 Johnson–Neyman 网格，`engine/R/tests/reference/process-goldens.json`）作为独立参考；R 单测逐项对照真实 runner 输出。该验证不等于声明所有官方选项、输出排版或特殊编码逐项一致。

## 暂停与不支持

- 研究项目、预注册、偏离治理和多人协作工作台；
- 云端账户、遥测、远程数据同步；
- 未在活动注册表登记的任意高级方法组合；
- 准实验因果识别：fixed effects、DiD / event study、IV / 2SLS、RDD、IPW / overlap 和 synthetic control；非随机比较仅作为上下文记录，不能解锁随机实验切片或生成因果表述；
- 三层或任意交叉分类结构、通用广义多层中介、连续时间模型、潜变量/高阶动态 SEM；
- 无人值守多源统计认证、突变/变形/模拟恢复平台。

这些方向的历史实现若有保留价值，位于 `archive/asset-packs/`，不参与默认运行、构建或测试。

## 权威顺序

发生冲突时依次检查：

1. 活动代码、路由和测试；
2. `project.manifest.json`；
3. 本目录当前文档；
4. `archive/` 中的历史记录。

历史记录只能解释“曾经做过什么”，不能证明“当前可用”。

## 状态词

- `active`：已接入活动入口并由当前门禁验证。
- `experimental`：可执行，但支持边界、样本适用性或数值验证仍需显式说明。
- `dormant`：仅在资产包，默认产品不可达。
- `deferred`：明确不在当前范围。
- `historical`：仅作追溯，结论可能已被后续代码替代。
