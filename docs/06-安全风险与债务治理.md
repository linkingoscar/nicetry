# 安全、风险与债务治理

## 安全边界

本地优先不等于无安全风险。活动系统必须保证：

- API 仅监听 loopback；
- 一次性凭据和来源校验不被绕过；
- 数据读写请求（含 GET 数据端点）必须携带会话令牌；公开白名单仅 health、demo、能力目录与 SSE 进度流；`/api/docs` 与 `/api/openapi.json` 不在公开白名单内，需要会话令牌；空或过短的 `RESEARCHPATH_SESSION_TOKEN`/`RESEARCHPATH_BOOTSTRAP_TOKEN` 会拒绝启动（fail closed），不得静默关闭鉴权；
- 用户可控路径经过规范化、containment 和对象身份绑定；
- 归档解压限制条目数、单文件大小、总大小和路径穿越；
- R 以参数和受控文件通信，不拼接用户命令；
- 原始数据、日志和结果不进入版本库；
- 错误响应不暴露任意本机路径或敏感内容；SSE 事件只投影白名单字段，错误原文经授权 GET 读取；
- 生产静态托管设置安全响应头（nosniff、X-Frame-Options、CSP）；前端导出路径与后端 XLSX 使用同一套公式注入转义。

2026-07-15 安全审计是历史快照，已归入 `archive/project-history/audits/`。其 finding 不能直接代表当前代码仍存在或已消失；需要用当前测试和代码重新验证。

## 主要持续风险

| 风险 | 控制 |
| --- | --- |
| 统计方法名与实际执行不一致 | `methodExecution`、显式回退、警告码清单（见 02） |
| 高级能力被过度宣传 | registry + slice + `executionAvailable`，并以 `maturityLevel`、`publicationEligibility` 和资格理由分离“可运行”“已验证”“可作为论文主分析” |
| 路径越界或对象错绑 | containment、identity、resource budget |
| R 包升级数值漂移 | `testthat` 细粒度测试 + Python 集成 + Full |
| Diary R 逻辑复制分叉 | 共享数据准备/中心化 helper，禁止新增复制 |
| 历史文档误导当前实现 | 活动文档限制为本目录 10 份，历史集中归档 |
| 资产包被误当活动源码 | manifest 只登记恢复切片，默认门禁排除 archive |
| 匿名连接耗尽 SSE 监听器 | 每 run ≤2、全局 ≤50 监听器上限，超限降级轮询 |

## 债务登记

活动债务使用 `docs/debt-register.json`，结构由 `debt-register.schema.json` 约束。只有可复现验收证据齐全才能标为 `closed`。

发现即登记：

- 开发、审查、审计或验证过程中确认的问题（统计正确性、安全、契约漂移、性能、架构、测试缺口等）必须及时登记为债务条目，包含证据、验收条件和优先级；
- 登记与发现尽量同批完成，最迟不得晚于当次任务/会话结束；问题不允许只存在于对话、代码注释或审查报告中；
- 修复在同一债务条目中闭环：状态改为 `closed` 并附可复现的 `closureEvidence`（测试、Harness 运行、验证脚本）；不能靠删除描述来关闭；
- 每次编辑后必须通过 `debt-register.schema.json` 校验。

状态：

- `open`：已确认且未开始；
- `in_progress`：正在处理；
- `implemented_pending_verification`：代码完成、门禁未闭环；
- `blocked`：存在明确外部阻塞；
- `accepted`：明确接受且记录理由/期限；
- `closed`：全部验收条件有当前证据。

文档中的建议不自动成为已登记债务；代码中发现的问题也不能仅靠删除描述“关闭”。

## 变更审计规则

- 安全、性能、全仓清理和发布准备前先读工程与验证文档。
- 先做只读盘点，确认目标，再执行移动、删除或恢复。
- Git 历史可恢复的冗余文档允许删除；原始审计证据保留在 archive。
- 不把历史测试数量复制成永久指标。
- `project.manifest.json`、文档和活动路由不一致时，按代码修正文档并补门禁。

## 事故或高风险修复

1. 固定触发条件和对象身份；
2. 建立最小回归测试；
3. 修复 service/engine 的根因；
4. 验证 HTTP 映射、导出和恢复路径；
5. 运行 Quick 与 Full；
6. 更新债务登记和当前文档；
7. 保留必要的复盘证据，避免把临时日志当长期文档。
