## PROCESS 的点按流程

1. “更换模型”中选择快捷模板，或从 X→Y 开始自定义；切换前确认替换当前编辑。
2. 在变量库搜索并点选变量，选择角色，再点“分配到所选角色”；支持键盘和原有拖放，也可在角色槽下拉选择。
3. 编辑区分为“变量与控制”“路径与调节”“估计设置”。右侧不再重复编辑同一份设置，只负责检查、冻结、运行和下载。
4. 新增控制变量创建真实模型节点与方程指派；删除节点/路径同步清理调节、控制方程及中心化引用。W/Z 连向有多条入边的结果节点时，要求明确选择被调节路径。
5. 冻结后的任何规格编辑、撤销或重做使冻结版本失效，重新检查和冻结后才能运行。运行时禁止修改模型；恢复草稿和切换上下文会重置撤销历史。
6. 当前模型结果单独展示。运行入口保持唯一，下载按钮区分结果/复现包和含数据的结果包。

识别目录含 55 个 PROCESS 编号；快捷模板只有 14 个：1、2、3、4、5、6、7、8、14、15、21、22、58、59。其他编号通过自定义结构识别，能否执行仍由服务端验证决定。本轮浏览器真实计算覆盖 Model 4，不等于逐个独立复核了 55 个编号。
