# 产品工作流与交互

## 首屏与两条主路径

首屏只回答一个问题：用户是在规划新研究，还是分析已有数据。

### 规划新研究

1. 声明研究问题与估计目标；
2. 声明计划中的时间结构、依赖结构和研究设计；
3. 设计变量、构念、题项和测量时点；
4. 使用不依赖真实数据的样本量、功效、精度和敏感性工具；
5. 形成与当前能力边界一致的分析计划。

当前首个活动切片是通用功效与精度。功效不是已有数据分析末尾的附加项，也不要求先创建数据版本。

### 分析已有数据

1. 先声明数据结构，再导入数据；
2. 导入后确认变量角色并检查所选结构；
3. 完成当前方法所需的数据、缺失或测量准备；基础原始变量分析无需先建构念；
4. 根据研究问题进入当前结构允许的方法；
5. 显式运行所选方法，记录数据、可空测量身份、样本、种子和参数；PROCESS/SEM 另需冻结模型版本；
6. 阅读结构化结果、警告、执行记录和可复现导出。

## 工作区导航与方法查找

工作区固定为“数据准备 / 统计分析 / 路径与 SEM / 方法目录”。标签旁的状态只说明准备情况，不能用“已拟合”或“计算中”代替真实任务状态；方向键与 Home/End 可切换工作区。

导入前展示研究结构选项；导入后默认收为当前时间、依赖与设计的摘要，通过“修改研究结构”展开编辑。嵌套提示、保存失败和待确认要求仍直接显示，不随版本诊断一起隐藏。

“统计分析”用于常用单项分析；“方法目录”提供跨方法检索，支持关键词、中文分类、匹配数量和清除筛选。常用实证入口优先排列，只显示注册表允许执行的入口。选择方法后进入对应的变量与参数配置，打开配置不会启动估计；专用向导显示时收起目录，返回后保留当前筛选并恢复按钮焦点。任务运行期间需先完成或取消，再返回目录。

方法页先呈现可执行操作，版本 ID、角色快照、上下文哈希放入“版本与诊断详情”。未满足的前置条件、警告、方法支持边界与发表资格仍可查看；不可执行的能力不作为产品入口展示。准备状态不等于模型已通过验证或达到论文发表要求。

## 研究上下文的三个正交维度

顶层不再把横截面、纵向、日记和实验当作同一种分类。研究上下文分别声明：

| 维度 | 当前选项 | 作用 |
| --- | --- | --- |
| 时间结构 | 单次/横截面、追踪面板、密集追踪 | 决定波次、时间和滞后准备 |
| 依赖结构 | 独立、聚类/嵌套 | 决定 cluster、ICC、聚合与多层模型门槛 |
| 研究设计 | 观察性、随机实验、非随机比较 | 决定处理变量、对比与解释边界；非随机比较不提供因果识别 |

例如，班级内学生只测量一次是“横截面 + 嵌套”，重复测量实验是“面板 + 随机实验”。切换时间或依赖结构不会删除原始数据版本，但下游分析设置必须重新确认。

研究上下文由本地 API 按项目保存并带修订号，浏览器本地状态只用于启动回退。数据版本另行保存结构角色快照；因此项目设计发生变化时，旧数据版本的角色确认不会被静默沿用。

## 结构专属准备与方法

### 单次 / 横截面

独立数据进入变量语义、量表测量、相关、比较、回归、PROCESS 和 SEM。存在聚类时必须指定 cluster ID，并先经过嵌套横截面专属准备，检查 cluster 数、组规模、ICC 和设计效应；需要团队构念聚合时再计算 ICC(1)、ICC(2) 与 rwg。实证配置中的 `cluster 聚合变量` 只驱动这些聚合诊断，`组间差异变量` 另行驱动组间比较、测量等值性与 DIF，二者不会互相默认或替代。当前多层估计入口只开放单一 cluster 的两层 Gaussian LMM；已知聚类时不默认开放会忽略依赖结构的 PROCESS 画布。PROCESS 画布提供 55 个有效官方预设的搜索、路径预览和中介数量配置，并保留 14 个快捷入口。自定义从未绑定的 X/Y 槽位开始；拖到空白处先选角色、不自动补路径，也可点按新增角色。节点有可见属性编辑、角色交换与删除；点击连线可改端点、反转或删除，支持端点拖动重连、撤销和重做。不完整草稿可保存和刷新恢复，但不能冻结运行；运行中所有模型编辑受锁定。

### 追踪面板

进入 ID/波次和宽长格式映射、流失与间隔检查、纵向测量等值性，以及 CLPM、RI-CLPM、LCM-SR。结果必须呈现波次样本流、缺失策略和诊断；竞争模型、稳健性与功效模拟由用户显式选择，不默认附加运行。

### 密集追踪

进入 ID/时间戳、依从性、间隔与滞后质检，明确个体内/个体间中心化，再配置 LMM、GLMM、多层中介或观测变量 DSEM。前端不用横截面术语替代个体内效应。

### 随机实验与非随机比较属性

随机实验不是第四种数据结构。只有声明随机分配后，系统才会根据时间与依赖结构开放 factorial ANOVA/ANCOVA、单一组内因子的重复测量/混合设计或当前登记的 cluster-robust Gaussian GLM。非随机比较保留外部规则或自然分组的上下文，但不会开放这些随机实验切片，也不会生成准实验、政策冲击或因果效应表述。

## 缺失诊断与多重插补

缺失流程分为两段：

1. 数据准备阶段只做缺失率、模式、结构性缺失和完整案例损失诊断；
2. 正式 MICE 位于分析前夕，必须先声明下游核心分析模型。

当前通用 MI 切片要求 Rubin 合并的线性回归规格显式声明 Y、预测变量和协变量。每个插补变量的预测模型必须纳入全部核心分析变量；修改核心模型后需要重新验证插补规格。插补数据集仍保持不可变，但不能作为脱离分析目的的通用“清洗后数据”解释。多层 MI 必须显式指定 cluster，未登记的下游 pooled model 不冒充已支持。

验证后的 MI 规格记录核心分析模型的规范化 SHA-256 指纹。若 Y、预测变量、协变量或截距声明变化，而规格仍携带旧指纹，后端以 `MI_SUBSTANTIVE_MODEL_CHANGED_REIMPUTE_REQUIRED` 拒绝运行；重新验证会生成新指纹，正式结果据此追踪插补与分析模型的一致性。

## 方法呈现与状态

### 实证中心：按方法独立运行

实证中心采用“选方法 → 选变量/构念 → 设置参数 → 运行 → 查看本次结果”的操作顺序。菜单点击只切换配置，不启动计算。变量列表支持搜索、勾选、全选当前搜索结果与清空；首次进入不默认选中全部变量。

| 方法组 | 独立入口 | 核心配置与输出范围 |
| --- | --- | --- |
| 基础统计 | 描述统计、频数、缺失诊断、相关/偏相关 | 只处理所选变量；偏相关另外指定不重叠的控制变量 |
| 测量 | 信度、EFA、CFA、构念效度、共同方法诊断、测量等值性 | 选择已计分的构念及其题项；EFA 与 CFA 独立，等值性另选分组变量 |
| 比较与聚合 | 组间比较、ICC/rwg | 比较变量和分组变量分开；聚合另选 cluster 与构念，不连带执行组间比较 |
| 回归 | 分层回归、相对重要性、响应面 | 指定 Y、预测变量和可选控制变量；响应面指定两个焦点变量 |
| 重复测量 | 纵向模型、日记/多层模型 | 先选模型类型，再设置 ID、时间、变量角色、中心化与估计参数 |

菜单按能力注册表的 `executionAvailable`、适用上下文与可见性筛选，17 个入口不会无条件全部开放。嵌套和重复观测不能由菜单切换绕过独立观测假设。PROCESS/SEM、实验、多重插补、IRT/DIF 等已有专用入口继续从对应工作区进入；本次未为原有引擎增加未登记的估计器。

“只运行选中方法”允许明确的统计依赖：构念效度需要 CFA 的载荷与因子相关；相对重要性需要回归模型；ULMC 需要基准模型与方法因子模型比较；信度的 ω 需要其单因子估计。这些计算只服务当前方法，不触发整个实证报告。CFA 不顺带执行 EFA、Harman 或 HTMT bootstrap；普通回归不顺带执行相对重要性。

完成后只显示本次方法及其必要依赖，Excel 导出遵守相同范围，不生成未执行方法的空白表或失败结论。新请求不提供“全套论文整合表”操作。历史未声明 `procedure` 的 API 请求和旧结果保留原有整包兼容，不能把它们误标为新单项结果。

每次运行绑定数据版本、可空测量版本、样本/上下文、方法和参数。界面“分析记录”保留当前数据/测量组合最近 30 次运行的本地索引，结果继续由服务端任务保存；选择记录恢复该次配置与结果，不重新估计。清除浏览器存储会清除此索引，不删除服务端报告；跨数据或测量版本的记录不能混用。

交互参考 IBM SPSS 的分析菜单、变量选择和过程对话框模式（[官方入门手册](https://public.dhe.ibm.com/software/analytics/spss/documentation/statistics/27.0/en/client/Manuals/IBM_SPSS_Statistics_Brief_Guide.pdf)、[统计过程手册](https://public.dhe.ibm.com/software/analytics/spss/documentation/statistics/24.0/en/client/Manuals/IBM_SPSS_Statistics_Base.pdf)）；纵向、潜变量和多层模型采用 Mplus 的变量角色、模型类型、估计设置和诊断组织方式（[官方用户指南](https://www.statmodel.com/html_ug.shtml)）。这是操作逻辑参考，不代表与这些软件的默认统计量或估计器完全相同；当前估计方法、近似、成熟度及警告以项目实际结果为准。

### 草稿恢复、具体方法跳转与 SEM 操作

原始变量分析直接使用已确认字典，报告与 Excel 的测量身份为空，不伪造构念版本。需要量表定义的分析先在数据准备中保存构念、题项、反向题和计分规则；当前面板、日记与路径模型仍使用各自的数据/测量准备流程。

独立实证方法的配置保存在浏览器，键包含数据内容、字典版本、测量版本及上下文哈希。离开再返回或刷新恢复最近配置和已接受的任务；服务端已提交但页面离开后才收到响应的任务也可重连。上游身份变化使用新草稿，旧结果不会冒充当前样本结果。清除浏览器存储会丢失本地草稿/索引，服务端结果不因此被删除。保存失败会明确提示，不宣称已保存。

方法目录现在携带具体切片：例如 CLPM 直接选中 CLPM，LCM-SR 启用题项模式并补齐所需波次，DSEM 设置相应分析类型和必需参数。切换前确认草稿影响，尽量保留兼容变量与波次标签；取消保留原稿，任务进行中不自动排队切换。纵向等值性/ULMC、日记质量/MI/功效仍属于对应模型的诊断或附加分析，配置页的依赖与执行范围必须一并核对，不表示获得了独立的新估计器。

SEM 在“路径与 SEM”工作台选择：测量图检查因子与指标，结构图编辑回归关系，完整模型同时查看。点击因子“编辑测量”或下拉定位可用键盘调整题项、高阶因子；展开/折叠只影响显示。引擎切换会重建测量和估计选项，因此需确认，可撤销恢复。同一引擎重复选择不重置。模型检查通过后冻结，再手动运行；图上 B/SE/CI 使用真实结果尺度，不把显著性当作理论成立。

Excel 下载除本次方法的表格外，保留“方法与来源”，内含 reportId、datasetId、可空测量身份、选项、来源和警告；可用这些字段核对下载内容是否属于当前报告。

### 通用状态规则

- 取消顶层“高级方法工作台”；功效进入规划流程，MI、实验、多层和高级测量按研究上下文出现。
- “高级/实验性”是具体能力标签，不是用户目的地。
- `executionAvailable=true` 是全局执行门槛；前端还必须判断方法是否适用于当前研究上下文。
- `maturityLevel` 说明切片处于实验性、已验证或论文级就绪的哪一层；`publicationEligibility` 单独说明能否作为论文主分析。当前任何成功运行都不自动获得论文级资格。
- 专家模式只展开当前方法的高级参数，不能跨时间或依赖结构绕过统计边界。
- 状态来自持久化任务和结果；统计量由 R 产生，前端只格式化与可视化。
- 图、表、解释与导出引用同一结果 bundle；方法降级、缺包、未收敛、样本删除和估计器替换必须可见。

## 结果解释边界

- 横截面关联不自动表述为因果；
- 聚合证据不等同于多层模型，也不使用固定阈值自动作决定；
- 显著性不是模型质量或理论有效性的唯一证据；
- 模型边的“区间不含 0 / p<.05”只表示本次估计中的推断信号，不表示理论获得支持；“区间含 0 / p≥.05”也不表示效应不存在；
- 未配置的方法不展示推断性结果；
- 探索性、稳健性和主分析在结果与导出中分层标识；
- 论文表述建议必须能追溯到结果字段和实际执行方法。

### 清空当前数据

数据准备页在已导入数据上方提供“清空当前数据”。确认后退出当前数据、测量和模型上下文，清理导入文件/工作表与待跳转请求，刷新保持待导入状态；迟到的上游请求不会恢复已清空的数据。此操作不删除本机数据、已保存草稿或结果，也不取消后台分析任务。取消确认则保持原状态。
