# 06 统计验证与测试

> 文档版本：2.0（2026-07-18）
> 适用范围：核心与高级方法统一验证原则。`scripts/harness.ps1 -Mode Quick/Full/Release` 是工程入口；方法是否 `supported` 还需逐 slice 的独立金标准和论文输出 QA。

## 1. 质量目标

本项目的核心质量不是页面无报错，而是“输入、模型和设置相同时，得到可信且可追溯的统计结果”。统计引擎必须先通过数值验证，才能接入正式结果界面。

## 2. 验证分层

### 2.1 公式单元测试

覆盖：

- 均值、方差、相关、中心化和标准化；
- 反向计分、有效题项比例和量表得分；
- OLS 设计矩阵、系数、残差、R²、协方差矩阵；
- HC3 标准误；
- 乘积项、条件效应和简单斜率；
- 中介间接效应和调节中介指数；
- 百分位 bootstrap 分位数。

每个测试使用可手工复核的小数据集，包括常数列、完全共线、缺失和极端值边界。

### 2.2 协议测试

- 示例 ModelSpec 必须通过 JSON Schema。
- 无效角色、重复 ID、悬空路径和错误调节目标必须被语义校验拒绝。
- 画布坐标变化不改变统计模型哈希。
- 节点或估计设置变化必须改变统计模型哈希。
- R 输入和 ResultBundle 均执行 schema 校验。

### 2.3 金标准数值测试

建立私有 `validation-reference` 目录，保存以下对照结果：

- R `lm` 和 `sandwich` 等公认实现；
- 用户本机合法下载的最新 PROCESS 输出，仅作私有验证，不提交仓库；
- 后续 SEM 使用 lavaan 官方示例和独立计算结果；
- 手工构造的已知参数模拟数据。

每个 MVP 模型至少包含：无协变量、有协变量、中心化开关、缺失数据、HC3、强/弱交互和边界案例。

### 2.4 端到端测试

从真实文件导入开始，验证数据字典、构念、画布、运行、结果和导出包。至少提供：

1. 单一中介项目；
2. 单一调节项目；
3. Model 7 等价项目；
4. Model 14 等价项目；
5. 故意包含编码错误和缺失的失败项目。

### 2.5 高级方法切片验证

高级分析以 `(family, designType/modelType/method)` 为最小验证单元，不允许只运行一次 family runner 就认定整族完成。每个切片至少覆盖：

- 请求在 Pydantic/Schema/前端表单中真实可达；
- 适用设计、estimand、编码、缺失和 df/合并规则；
- 与独立实现或公开数据的数值对照；
- 不平衡、缺组/缺波、奇异、不收敛、超时、取消和损坏结果；
- ResultBundle 字段到前端表格、图形、APA 文本和导出的逐字段一致性；
- 相同数据/规格/seed 复现，以及资源预算和连续运行回收。

必须包含当前已知的反例回归：功效复杂 MC 稳定拒绝且无不可达执行分支、MI `pooledEstimates` 为空时不宣称合并、实验缺失效应量不写成 0、未实现 Games–Howell 稳定拒绝、纵向 FIML 与实际样本处理一致、前端 advanced estimate 使用 `label/degreesOfFreedom/confidenceLower/confidenceUpper`。已修复反例仍须保留回归测试，不能从清单中消失。

## 3. 数值容差

| 结果 | 同算法容差 | 跨软件比较规则 |
|---|---:|---|
| OLS 系数 | 绝对差 ≤ 1e-8 | ≤ 1e-6 |
| 经典/HC3 SE | 绝对差 ≤ 1e-8 | ≤ 1e-5 |
| t、p、R² | 绝对差 ≤ 1e-8 | ≤ 1e-5 |
| 条件效应/间接效应点估计 | 绝对差 ≤ 1e-8 | ≤ 1e-6 |
| bootstrap CI | 相同重抽样索引 ≤ 1e-8 | 不同 RNG 不做逐端点等值；改用固定重抽样索引或分布性质验证 |

不得为了“看起来接近 PROCESS”放宽基础回归结果。不同软件的 bootstrap RNG 或分位数约定可能不同，必须记录原因，不能用一个任意宽容差掩盖差异。

### 3.1 高级方法已冻结的公开金标准（2026-07-19）

“金标准”不是从 ResearchPath 当前输出复制一份 JSON。它必须由不调用产品 runner 的独立脚本生成，绑定公开数据出处、确定性派生步骤、数据 SHA-256、参考包版本、模型调用、比较字段和逐指标容差。当前可重跑入口为 `apps/api/tests/fixtures/advanced/reference/generate-goldens.R`，说明见同目录 `README.md`。

| 已验证切片 | 公开数据与派生 | Reference model | 冻结字段 | 容差 |
|---|---|---|---|---:|
| 单一组内因子重复测量 + 一个组间因子 | O'Brien–Kaiser (1985)，`afex::obk.long`；在 `id × treatment × phase` 内对五个 hour 作算术平均 | `afex::aov_car(value ~ treatment * phase + Error(id/phase), type=3)`；`anova(..., correction="GG", es="pes")`；`emmeans` 95% CI 与 Holm pairwise | GG 校正 F/df/p、Mauchly/GG ε、partial η²、EMM/SE/df/CI、contrast/SE/df/CI/p | 同锁定算法绝对/相对差 `1e-8` |
| 平衡 2×3 组间 ANOVA | R 官方 `datasets::ToothGrowth`，dose 显式转为三水平因子 | Type III `afex::aov_car` + `emmeans` | omnibus、六个 cell EMM/CI、Holm pairwise；空 cell 稳定失败 | 同锁定算法绝对/相对差 `1e-8` |
| ANCOVA | `carData::Moore`；fscore grand-mean centered | Type III `afex::aov_car` + `emmeans` | omnibus、调整 EMM/CI、Holm contrast；共线协变量秩亏失败 | 同锁定算法绝对/相对差 `1e-8` |
| 两层 Gaussian 随机截距 + 随机斜率 | Belenky et al. (2003)，`lme4::sleepstudy` 原始 180 行 | `lmerTest::lmer(Reaction ~ Days + (Days|Subject), REML=TRUE)`，Satterthwaite df | 固定效应/SE/df/t/p、随机方差/协方差、AIC/BIC/logLik、ICC、marginal/conditional R² | 迭代估计绝对/相对差 `1e-6` |
| 不平衡 group-mean centered LMM | 从 `sleepstudy` 按 subject 确定性删除 0–3 个末期观测 | `Reaction ~ Days_within + Days_between + (1|Subject)`；Satterthwaite/Kenward–Roger 分别冻结 | 中心化恒等式、固定效应/CI/df、cluster size、likelihood | 变换 `1e-12`；迭代估计 `1e-6` |
| 四波观测自回归 + ML FIML | lavaan 官方 `Demo.growth`；仅由已观测 y1/y2 确定单调 MAR 失访，波次 N 为 400/400/360/300 | `lavaan::sem("y2 ~ y1\ny3 ~ y2\ny4 ~ y3", estimator="ML", missing="fiml")` | 参数/SE/z/p/CI、拟合指标、`ntotal=400`、逐波 attrition/re-entry、缺失模式数 | 迭代估计绝对/相对差 `1e-6` |
| 四波非单调缺失 + ML FIML | 同一 `Demo.growth`，T3-only 与 T4-only 缺失集合不重叠 | 同一显式 observed autoregression | `ntotal=400`、T4 re-entry=30、参数/CI、fit 与缺失模式 | 迭代估计绝对/相对差 `1e-6` |

以上证明的只是表中精确切片，不能外推到多组内因子、任意混合设计、三层/GLMM、潜增长、RI-CLPM 或纵向测量等值性。包升级后必须先运行独立 generator 和产品 runner 双路复核；不能直接接受更新后的 golden。

对应数值失败回归固定为：MLM 梯度未收敛返回 `MLM_NONCONVERGENCE`；随机效应矩阵非正定返回 `MLM_RANDOM_EFFECTS_MATRIX_NOT_POSITIVE_DEFINITE`；奇异边界返回成功但必须含 `SINGULAR_FIT` warning；纵向非正定、未收敛和收敛后检查失败分别返回稳定错误码，且均不得产生 `status=succeeded` 结果。

## 4. 随机性验证

- 同数据、模型、设置和种子结果完全可重复。
- 改变种子只允许改变 bootstrap 相关结果，不改变点估计。
- 测试使用预生成重抽样索引验证算法，而不是依赖某一软件 RNG。
- 运行清单记录 RNG 类型、种子和 bootstrap 次数。

## 5. 数据导入测试矩阵

| 维度 | 案例 |
|---|---|
| CSV 编码 | UTF-8、UTF-8 BOM、GB18030 |
| 分隔符 | 逗号、制表符、分号 |
| XLSX | 多工作表、公式、日期、空表头、重复表头 |
| SAV | 变量标签、值标签、用户缺失、中文标签 |
| 数值 | 科学计数、千分位、NaN、Inf、负零 |
| 文本 | 中文、Emoji、前后空格、公式注入前缀 |
| 规模 | 小数据、20,000×200 基准、超宽数据 |

导入器必须返回明确告警，不能静默猜测失败的编码或日期。

## 6. 性能与稳定性

在目标 Windows 机器记录基准配置。MVP 门槛：

- 20,000×200 CSV 导入和概况生成 ≤ 15 秒；
- 5,000 次常规中介 bootstrap ≤ 60 秒；
- 长任务可取消，取消响应 ≤ 2 秒；
- 任务失败后项目可继续打开和重新运行；
- 连续打开、运行、导出 20 次无句柄和临时目录持续泄漏。

性能门槛可基于实测修订，但修订必须形成决策记录。

## 7. 展示验证

- 表格显示值与 ResultBundle 原值一致，格式化不得改变符号或数量级。
- 小 p 值显示为 `< .001` 时保留机器可读原值。
- 置信区间上下界顺序、置信水平和方法均可见。
- 图形轴和单位正确；简单斜率图使用模型预测，不直接连接原始分组均值。
- 路径图的路径、方向和调节目标与 ModelSpec 一致。

## 8. 发布质量门

正式版本必须满足：

- P0 单元和端到端测试 100% 通过；
- 金标准数值差异全部在阈值内或有已批准说明；
- 无静默数据转换；
- 无错误状态被标记为成功；
- 每个正式结果可导出完整运行清单；
- 未完成或未验证的分析模式在 UI 中不可进入。

发布质量分两层：

1. **工程可发布**：Quick/Full/Release Harness、迁移、安全、恢复、依赖和 bundle 门禁通过；
2. **方法可支持**：具体切片再满足独立数值金标准、真实研究试用、方法专家复核、报告/图形 QA 和适用边界。

工程可发布不能自动把 `experimental` 升为 `supported`；family runner 可执行也不能替代 slice 级方法可支持证据。

## 9. 缺陷分级

- S0：数值错误、数据损坏、结果错配，立即阻止发布。
- S1：关键流程无法完成或复现材料缺失，阻止发布。
- S2：非核心功能错误或方法提示不完整，修复后进入下一候选版本。
- S3：视觉、文案或低影响体验问题，可进入积压。
