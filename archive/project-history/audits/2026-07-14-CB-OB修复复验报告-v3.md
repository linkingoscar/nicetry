### 4.2 独立或金标准对照

1. **CFA**：使用 lavaan 及 `HolzingerSwineford1939` 公共数据，核对标准化载荷和主要拟合指标；当前口径达到实施计划要求的 `1e-5` 容差。
2. **Logistic**：使用独立 NumPy IRLS 重新估计系数，并独立计算 HC3 sandwich 协方差，与 API 结果交叉核对。
3. **Promax**：除接口成功外，直接验证 Φ 的对称性/单位对角线，以及结构矩阵和共同度的定义恒等式，避免“能运行但矩阵含义错误”。
4. **FIML**：合成部分缺失样本验证 300 条观测均进入 lavaan 的 FIML，而非退化为 listwise deletion；同步核对缺失模式输出。
5. **WLSMV**：合成有序指标验证 scalar 等值性约束落在 thresholds，而不是连续指标 intercepts。
6. **边界测试**：完全分离 Logistic 明确失败且不生成伪结果；无效方法参数返回 422；非正定 CFA、不可评估效度和不收敛 SEM 均不再伪装成成功。

## 五、模拟 CB/OB 使用结论

| 场景 | 当前结论 | 使用提示 |
|---|---|---|
| OB 横截面链式中介 Model 6 | **可用** | 报告特定间接、总间接及 BC 区间；注意 BC 不是 BCa |
| CB/OB 调节与调节中介 Model 1/7/8/14/15 | **可用** | 连续结局与二水平结局均可运行；二分类路径需说明 logit/概率尺度 |
| EFA Promax + CFA + 信效度 | **可用** | 混合符号载荷、非正定或 CFA 失败会给出警告/不可评估，而非自动美化结果 |
| 潜变量 SEM 与多组等值性 | **有条件可用** | ML/FIML 和有序 WLSMV 主流程可用；应检查收敛、Heywood、非正定与每组样本量警告 |
| 两组/多组横截面差异 | **可用** | 方差不齐优先解释 Welch/Brown–Forsythe 与 Games–Howell |
| 2×2/多因素、重复测量或混合实验 | **尚未完整支持** | 当前可用回归编码处理部分问题，但不是完整实验设计工作流 |
| 员工嵌套团队的多层中介/SEM | **不支持** | 不能忽略聚类结构后按单层结果发表 |
| 纵向、交叉滞后、增长模型 | **不支持** | 当前没有时间结构和纵向等值性流程 |

## 六、仍需继续改进的项目

以下是能力扩展或证据增强，不属于本轮已修问题的回归失败：

1. **扩充 CFA 金标准矩阵**：目前严格 lavaan 对照集中在一个公共数据集。建议再加入差拟合、近奇异、两指标因子及缺失数据等 3–5 个固定数据集。
2. **扩充 WLSMV 金标准验证**：现有合成契约测试能够确认 thresholds 约束，但应再使用公开有序数据对照 lavaan/Mplus 的 scaled 指标与差异检验。
3. **增强 SEM 画布体验**：增加残差相关的可视化编辑、参数约束、撤销/重做和模型识别的图形化提示。
4. **补齐 CB 实验工作流**：优先开发多因素 ANOVA/ANCOVA、计划对比、操纵检验、重复测量与混合设计。
5. **补齐 OB 嵌套数据**：增加 ICC、cluster-robust SE、两层模型与多层中介。
6. **补齐缺失与稳健性工具**：增加多重插补、敏感性分析、异常值稳健估计和并列稳健性表。
7. **补齐纵向与功效分析**：纵向等值性、RI-CLPM/增长模型、模拟功效和最小可检测效应应作为独立里程碑实施。

## 七、发布建议

建议当前版本定位为：

> **面向单层、横截面 CB/OB 问卷与常见行为结果研究的可复现实证工作台，支持观测变量 PROCESS 模型、EFA/CFA、常用组间比较和基础潜变量 SEM。**

在这个定位下，当前版本具备进入真实论文试用的条件。正式使用时仍应保留以下治理要求：固定并记录 seed；导出并归档方法来源表；检查所有警告和不可评估项；对复杂 WLSMV、边界样本和二分类间接效应保留第二软件复核；不要把当前产品外推为多层、纵向或全类型实验分析平台。
