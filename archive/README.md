# ResearchPath 归档

本目录保存不参与当前默认产品的开发资产和历史证据。归档内容不参与默认运行、构建、类型检查、覆盖率或 Harness。

| 目录 | 用途 | 入口 |
|---|---|---|
| `asset-packs/ob-cb-expansion` | 高级 OB/CB 方法和研究协议；七个切片已选择性恢复 | `asset-packs/ob-cb-expansion/README.md` |
| `asset-packs/validation-lab` | Golden、多源认证、突变/变形/模拟工具 | `asset-packs/validation-lab/README.md` |
| `project-history` | 历史审计、ADR、维护证据和退出门禁的旧基线 | `project-history/README.md` |

归档不是垃圾目录，也不是当前源码目录。不要在其中进行日常修补；恢复需求出现时先建立明确范围，再把所需最小文件迁回活动目录。

## 保存原则

- 有独立追溯或恢复价值的资产长期保留。
- 资产包内尽量保留原相对目录，方便追溯和选择性恢复。
- 根目录不得散放一次性生成脚本或临时运行输出；已确认有保留价值的材料应归入相应资产包。
- 归档文件默认不进入构建、测试、覆盖率和发布门禁。
- 资产包中的脚本可能依赖归档前路径，必须先阅读恢复说明并完成路径适配，不能直接执行。
- Git 已完整保存、且没有独立证据价值的重复阶段文档无需再保留归档副本。
